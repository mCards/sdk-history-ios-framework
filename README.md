# sdk-history-ios-framework
SDK containing common model classes used to show history

## Importing
The SDK can be imported via SPM (Swift Package Manager).
- Add the package in the dependencies section of the Swift Manifest file. For example, `.package(url: "https://github.com/mCards/sdk-history-ios-framework", from: "1.0.0")`
- In the tartet dependencies section add: `.product(name: "HistorySDK", package: "sdk-history-ios-framework")`
